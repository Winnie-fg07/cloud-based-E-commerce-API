Cloud-Based E-Commerce REST API By ✨Winnie✨

A cloud-ready FastAPI backend application for managing products, users, and orders with JWT authentication and SQLite database integration.

Features

  • JWT Authentication
  • Product Management
  • Order Management
  • SQLite Database
  • Inventory Validation
  • Protected Routes
  • Cloud Deployment Ready

API Endpoints

Method Endpoint Description
POST /register Register a new user
POST /login Login and receive JWT token
GET /products Retrieve all products
POST /products Create a new product
GET /orders Retrieve all orders
POST /orders Create a new order

Technologies Used

  • FastAPI
  • SQLite
  • SQLAlchemy
  • JWT Authentication
  • AWS S3 Static Hosting
  • HTML & CSS
